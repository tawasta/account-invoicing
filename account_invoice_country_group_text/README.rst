=====================================
Acccount Invoice - Country Group Text
=====================================

* Adds a new field to country groups to store the text
* Adds the text to account invoice prints

Configuration
=============
* Go to Invoice settings and check "Show country text for this company's Invoice print" (the setting is company-specific)
* Configure the country group texts in Contacts -> Configuration -> Country Group

Usage
=====
* Print an invoice for a customer whose country has some country group texts defined
* Texts show up below payment term
