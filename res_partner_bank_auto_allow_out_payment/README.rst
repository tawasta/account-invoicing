=========================================
Auto Allow Out Payments On Bank Accounts
=========================================
Automatically allow all added bank accounts. This automatically sets bank accounts 
as trusted.

Installation
============
* Install the module

Configuration
=============
* Go to the Accounting/Invoicing settings and enable the toggle 
"Automatically make bank accounts trusted"

Usage
=====
* After installing and enabling the settings toggle, all new bank accounts 
are automatically made trusted
* Chatter message will appear in the bank accounts form of it becoming 
trusted
