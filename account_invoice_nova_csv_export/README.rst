===========================================
Account Invoice: Nova-Compatible CSV Export
===========================================
* Enables creating a CSV file of customer invoices, to then
  be imported into Nova.


Configuration
=============
* None needed

Usage
=====
* Go to customer invoices list view, select some invoices and then
  Actions -> CSV Export (Nova)

Known issues / Roadmap
======================
* This is a barebones solution made for a specific export/import need
  and use case. More development is likely needed if you want to take
  this module into wider use.
