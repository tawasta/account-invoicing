=======================================
Print PDF file after posting an invoice
=======================================

Select reports that use account.move model to automatically
print the reports after Confirming an invoice.

Configuration
=============
Select a report (ir.actions.report) and mark "Print report on Post"
field as True.

Usage
=====
Confirm an invoice after a proper configuration has been done
